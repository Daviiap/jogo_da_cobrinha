# 🐍 Cobrinha

Jogo da cobrinha feito com HTML, CSS e JavaScript puro, sem dependências.

## Como jogar

- **Setas** ← ↑ → ↓ movem a cobra
- **Espaço** pausa e continua
- Cada comida vale 1 ponto e deixa a cobra um pouco mais rápida
- As bordas levam para o outro lado; só bater no próprio corpo faz perder
- O recorde fica salvo no navegador

## Rodar localmente

Abra o `index.html` no navegador.

## Publicar no GitHub Pages

1. Crie um repositório vazio no GitHub (sem README, `.gitignore` ou licença).
2. Conecte e envie:

   ```bash
   git remote add origin git@github.com:SEU_USUARIO/NOME_DO_REPO.git
   git push -u origin main
   ```

3. No repositório, vá em **Settings → Pages**, em **Source** escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`, e clique em **Save**.
4. Em um ou dois minutos o jogo estará em `https://SEU_USUARIO.github.io/NOME_DO_REPO/`.
